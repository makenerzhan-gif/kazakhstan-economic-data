Экономика Казахстана: ключевые индикаторы

Данные пайплайна kazakhstan-economic-data на 2026-11-13. Расчётные показатели (базовая инфляция, реальная ставка, разрыв выпуска, кредитный цикл) — оценки репозитория, не официальная статистика; методика — в примечаниях датасетов.

Период:
Источники: БНС АСПР РК, Национальный Банк РК, Министерство финансов РК, KASE, Всемирный банк; расчёты — scripts/fetchers/analytics.py. Страница собирается скриптом scripts/build_dashboard.py после каждого прогона.
